# TV ბრაუზერი

მსუბუქი ბრაუზერი Samsung Tizen ტელევიზორისთვის (შემოწმებულია UE55TU8300-ისთვის, Tizen 5.5).

- ერთი გვერდი ერთდროულად, ჩანართების გარეშე — მთავარ ეკრანზე დაბრუნებისას გვერდი მთლიანად იშლება და მეხსიერება თავისუფლდება
- რჩეული საიტები (`sites.js`), დამატება/წაშლა პულტიდან
- გათიშვის შემდეგ „გაგრძელება“ ბოლო გვერდზე
- მენიუები — პულტით; საიტის შიგნით — USB მაუსით

## პულტი
| ღილაკი | მოქმედება |
|---|---|
| ისრები / OK | ნავიგაცია / გახსნა |
| BACK | უკან (პირველ გვერდზე — მთავარი) |
| ↑ (საიტზე) | ზედა პანელი |
| 🔴 | მისამართი / ძებნა |
| 🟢 | სუფთა გადატვირთვა |
| 🟡 | საიტის დამატება |
| 🔵 | ბარათის წაშლა |

## დაყენება
TizenBrew Installer → Install app from GitHub → `Ditodumbadze/tv-browser`
(ტელევიზორზე Developer Mode, Host PC IP = კომპიუტერის IP).
