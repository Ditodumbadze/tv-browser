# TV ბრაუზერი

მსუბუქი ბრაუზერი Samsung Tizen ტელევიზორისთვის (შემოწმებულია UE55TU8300-ისთვის, Tizen 5.5).

- ერთი გვერდი ერთდროულად, ჩანართების გარეშე — მთავარ ეკრანზე დაბრუნებისას გვერდი მთლიანად იშლება და მეხსიერება თავისუფლდება
- რჩეული საიტები (`sites.js`), დამატება/წაშლა პულტიდან
- გათიშვის შემდეგ „გაგრძელება“ ბოლო გვერდზე
- **კურსორის რეჟიმი (ნაგულისხმევი):** პულტის ისრებით კურსორი, OK — დაჭერა, კიდესთან — გადახვევა;
  აპლიკაცია გვერდს თავად ტვირთავს, ამიტომ კურსორი აჭერს ბმულებს, ღილაკებს, ძებნის ველს და ჩადგმულ პლეერებს
- რეკლამის სკრიპტები იშლება, ბანერები იმალება, popup-ები იბლოკება
- ვიდეო: ▶/⏸, ⏩ (+10 წმ), ⏪ (−10 წმ) პულტიდან; CH ▲/▼ — გვერდის გადახვევა
- **მაუსის რეჟიმი** (🔵): ჩვეულებრივი ჩატვირთვა USB მაუსისთვის — თუ რომელიმე საიტი კურსორის რეჟიმში არ მუშაობს

## პულტი
| ღილაკი | მოქმედება |
|---|---|
| ისრები / OK | ნავიგაცია / გახსნა |
| BACK | უკან (პირველ გვერდზე — მთავარი) |
| ↑ ზედა კიდესთან | ზედა პანელი |
| 🔴 | მისამართი / ძებნა |
| 🟢 | სუფთა გადატვირთვა |
| 🟡 | საიტის დამატება |
| 🔵 | მთავარზე: ბარათის წაშლა · საიტზე: კურსორი ⇄ მაუსი |

## დაყენება
TizenBrew Installer → Install app from GitHub → `Ditodumbadze/tv-browser`
(ტელევიზორზე Developer Mode, Host PC IP = კომპიუტერის IP).
